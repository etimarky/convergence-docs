# Allowed Values


## Allowed Values


## Create Allowed Values Lists (AVL)

Go to the Allowed Values page.

In "Add New AVL...", type desired name for the Allowed Value List.

Once you type the desired name, click on Apply or press Enter on your keyboard.

## Edit Allowed Values List(AVL)

Editing an AVL is split into two sections: editing the name of the list itself, and adding/editing values.

In the Classification properties under the chosen categories, click on Details.

All values stored in AVL are displayed under Values.

In Where Used, you can see under which categories the AVL is located.

Click on Close to go back to the Classification page and select Edit to begin editing your AVL.

Click on the drop-down next to Details and select Edit.

Also, an AVL can be unassigned by clicking on Unassign.

## Values can be added manually

Values can be added if there are existing values under the attribute where the AVL was created;

this feature automatically compiles all existing values and allows you to add them in one step.

Go to the Allowed Values page to select an attribute.

Under Values, select Edit Values.


![Page 6](../assets/other__allowed-values_images__page-006.jpg)


## Edit Allowed Values Lists

In order to add all values under the attribute where the AVL was created, click on Add Suggested to

add all existing values.

Optionally, you can add new values by simply typing a value in the Add New Values box.; this option

allows you to add new values to the AVL.

Now, click on Add All Suggested to add all values or select the checkboxes to add individual values.


![Page 7](../assets/other__allowed-values_images__page-007.jpg)

## Load Values from a Text File

Values can be imported from .csv or .txt file by clicking on Load Values.

Go to the Allowed Values page.

Select the desired file and click on Open.

Then, click on Load Values to add all values from the file.

## SmartCreate


## Create Parts

SmartCreate is used to create new individual parts.

Select SmartCreate from the menu on the top left.

Select a category from the category data model located on the left side of the screen. Attributes for the

selected category will be displayed on the right.


## Locate the desired category and select "Continue."

The third screen will display only Key Attributes for data entry.

As each value is entered, the possible duplicates will appear at the bottom.


![Page 16](../assets/other__allowed-values_images__page-016.jpg)


## SmartCreate

If the part already exists, it can be duplicated by utilizing a qualifier to essentially tell DFR that it is a

new part.

Once there are no possible matches, the item will be created as New.

Select Continue.

Begin by entering Item Number and Item Description.

Minimally, the Item Number needs to be entered in order to save the new part.

Then use the attribute table and fill in any applicable attributes.

Users may utilize the ability to add to a batch, deliverable or item access group from this screen as well.

Select Save when complete.
