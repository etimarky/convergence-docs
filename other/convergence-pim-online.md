# Convergence PIM Online

## Convergence PIM Online

## SmartTeardown

The SmartTeardown module allows users to break down products into a product structure and compare

different modules side by side (including images). This new CDS PIM module will not only allow service

clients to store any competitive intelligence data they collect but make it a seamless process to deliver

data to employees. Long gone are the days of finding the latest PowerPoint or Excel sheet. Stay up to

date with dynamic data utilizing the power of CDS PIM Online!

## Adding a Product

A product in SmartTeardown refers to an item, appliance, part etc. such as a "dryer, washing machine,

## dishwasher, etc."

Navigate to SmartTeardown.

The first screen that appears will be where the user adds a product/model.

Fill in all pertinent information. An image can be added at this step as well.

All information must be filled in.

If features were identified in Family Management, these will appear as an option on this page too.

## Family Management

Family Management allows the user to create product families and segments that will form the product

hagiarchy.

A product family must be added on this screen, otherwise the user will not be able to load segment data

against it.

Inside the SmartTeardown module, select Family Management.

Once inside Family Management, the user has the option to add, edit, delete or export a family.

To add a family, navigate to the left half of the screen and select the orange icon. This will allow the

## user to then select "Add."

![Page 8](../.gitbook/assets/other__convergence-pim-online_images__page-008.jpg)

## SmartTeardown

Fill in all pertinent information such as Name and Description.

The user can also add an image at any time, whether that's upon initial creation or while going back and

editing at a later time.

On the right side of the screen, families are able to be edited, deleted or exported.

![Page 9](../.gitbook/assets/other__convergence-pim-online_images__page-009.jpg)

## SmartTeardown

Regions, feature sets and product structure are also built out and determined on this screen as well.

Regions are defined in General Management and once a region is selected, a product with the selected

region(s) will only show up when that region is chosen in the drop down on the top right of the screen.

If no regions are selected, all regions are assumed.

![Page 10](../.gitbook/assets/other__convergence-pim-online_images__page-010.jpg)

## SmartTeardown

Feature sets are set up on this screen as well. Simply type in a feature set and select enter to add it.

These can then be selected on products when creating on the SmartTeardown main screen.

Feature sets can also be edited and deleted on this screen as well.

![Page 11](../.gitbook/assets/other__convergence-pim-online_images__page-011.jpg)

## SmartTeardown

Lastly, Product structure is built out on this screen.

This is similar to building out structure in SmartClass. Define classes/categories and build them out.

There can be no more than 5 levels in the product structure.

Product structure can also be deleted and edited on this screen as well.

If a user deletes product structure that has segment data attached to it, the data will be lost

indefinitely.

There will be one warning notifying the user of this. The deletion cannot be undone.

![Page 12](../.gitbook/assets/other__convergence-pim-online_images__page-012.jpg)

## SmartTeardown

Product Structure once built out can be exported, which will automatically create a template that can

be edited and later imported back in to include segment data.

Below is an example of an export of dryers.

When filling out segment data information, Region, Materials and Manufacturer will appear as drop-

down options which easily allow the user to select these options based on information set up in General

Management. The user will not be able to freely type in information in these areas.

Model must be filled in as well but will not appear in a drop down.

Fasteners and Segment data tabs are important in this template but "ListInfo" is just that- a list and can

be ignored when setting up segment and fastener data.

## General Management

In General Management, the user will be able to add or remove pertinent information such as but not

limited to Product Manufacturers, Materials and Fastener Types. These will be critical in creating

products on the Teardown home screen.

The user must have SmartTeardown permissions in order to view this page.

Navigate to SmartTeardown, select "Management" in the top Right, and then "General Management."

Choose the area that needs information added. Each page allows to "add" new.

![Page 15](../.gitbook/assets/other__convergence-pim-online_images__page-015.jpg)

## SmartTeardown

This will prompt a window which allows the user to fill in information and in some cases, add an image

at the same time.

Users can select entries and edit or delete them as well.

Edit is in the top right, as well as delete.

![Page 16](../.gitbook/assets/other__convergence-pim-online_images__page-016.jpg)
