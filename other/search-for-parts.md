## Multi-Classify

If you would like to have an item be in multiple categories at the same time, you can Multi-Classify an

item.

Navigate to the item you would like to multi-classify in SmartFind.

In the top right of your screen, click the button with folder on it highlighted below.

Now in the pop-up window, drill down to the category you would like to add the item to.

Click on the category and click confirm in the bottom right.

## Reclassify Parts

In SmartFind, you are able to move a part from its existing category to a different category; this process

is known as reclassifying a part.

First, select a random part from any category at any category level.

## Review the root (the category where the part is located)

In this example, the part is located at the lowest category level. This part can be moved up to its parent

category or be moved to the lowest level of any parent category.

Click on Reclassify.

Now you are able to see where the part its classified and what attributes pertain to that category.

You are able to reclassify the part by clicking on any of the category levels.

## Copy from Another Part

In SmartFind, you are able to copy all attribute values from one item and paste them over another item.

This feature will override all existing attribute values to a part with the values "copied" from the desired

part.

Go to any category at any level or simply select a part.

In this case, Scroll Compressors is shown and the part that will be updated is "001-27421" and we will

copy the attribute values from "001-27422".

All attribute values from "001-27422" will be copied, except for the values that are blank.

Those null values will not override the values in "001-27421", instead the existing values in "001-27421"

will be kept.

Click on the part "001-27421".

Review all attribute values and click on Edit.

![Page 13](../.gitbook/assets/other__search-for-parts_images__page-013.jpg)

## Item Details

Click on Copy Anther Item.

Enter the item number where the data will be copied from; item number "001-27422" is typed.

Click on Search.

Make sure Classification Data and Attribute Data are selected.

Click on Copy.

![Page 14](../.gitbook/assets/other__search-for-parts_images__page-014.jpg)

## Item Details

Now, all attribute values are shown with all the new updates as shown.

Click on Save to make all changes.

## Add Attributes to a Display Tab

1. First navigate to SmartClass
2. Next, find a leaf category you would like to work in. Click on an attribute as shown below.
3. Click on the blue "Edit" button in the top right of the right hand panel that has popped up.
4. Drop down the "Properties" menu and scroll down until you find "Display Tab". Enter the name of the

tab you would like to have added.

5. Click on the green "Save" button at the top right of your screen.
6. You will now see the display tab in the item details page, with the one attribute that you added to it.
