# Attributes(Master Attributes)

## Attributes(Master Attributes)

If you change any of the properties to the original or localized attribute, the same changes will be done

to the original or localized attribute.

In this example, data type is changed from String to Integer.

## Attribute Groups

Attribute groups are useful when there are multiple categories that are using the same attributes.

These attributes are grouped together and placed easily in bulk onto a category/categories.

Click on the highlighted icon to go to the Attribute Groups page; the screenshot below represents the

Attribute Groups page.

### Click on the links below to access the following pages

## Create and Delete Attribute Groups

![Page 4](../.gitbook/assets/other__attributes-master-attributes_images__page-004.jpg)

## Attribute Groups

## Create and Delete Attribute Groups

In the Attribute Groups page, click on "Add New Attribute Group" and type the desired name for the

new Attribute Group.

Once you type the desired name, click on Apply or press Enter on your keyboard to save.

A description can be added under the Description box.

Click on Save to make these changes.

![Page 5](../.gitbook/assets/other__attributes-master-attributes_images__page-005.jpg)

## Attribute Groups

The new Attribute Group has been created.

Add Attributes to Attribute Groups from Attributes Groups Tab

In the Attribute Groups tab, select an Attribute Group and click on Edit to make changes to the

Attribute Group.

## Add Attributes to Attribute Groups From Classification Tab

Alternatively, attributes can be added from the Classification tab.

Select a category, and checkmark the attributes to be added.

Click on operations, and select Add to Group...

Now select the Attribute Group where the chosen attributes will be added.

Click on +Add.

![Page 10](../.gitbook/assets/other__attributes-master-attributes_images__page-010.jpg)

## Attribute Groups

Go back to the Attribute Groups tab and select the Attribute Group to display the added attributes.

## Add Attributes to Attribute Groups From Attributes Tab

Alternatively, attributes can be added from the Attributes tab.

Select an attribute and click on Edit.

Click on the Arrow next to Attribute Groups.

Click on +Add.

![Page 11](../.gitbook/assets/other__attributes-master-attributes_images__page-011.jpg)

## Allowed Values Lists(AVL)

Allowed Values Lists is a tool used to target individual attributes and define a list of specific,

standard string values that can apply to the attribute. The user selects a category and an

attribute to create a list of possible values for that attribute in that category.

Click on the highlighted icon to go to the Allowed Values page; the screenshot below represents the

Allowed Values page.
